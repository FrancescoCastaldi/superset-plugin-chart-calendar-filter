# 📂 Jest Mocks (`/test/__mocks__`)

> **Environment Simulators for Unit Testing**

This directory hosts Jest mock modules designed to simulate the Apache Superset environment during isolated testing.
- **`@superset-ui/core`**: Stubs core Superset dependencies (e.g., Theme configuration, logging).
- **`emotion-styled`**: Simulates CSS-in-JS behavior for `@emotion/styled` during snapshot testing.
