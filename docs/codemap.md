# docs/

## Responsibility

Project documentation directory containing changelogs (`CHANGELOG.md`), installation instructions (`INSTALL.md`), contributor guides (`CONTRIBUTING.md`), installer guide (`INSTALLER.md`), and UI screenshots (`screenshots/`).

## Design

Structured markdown documentation following GitHub Flavored Markdown (GFM) standards, detailing project history, installation procedures, and visual UI guides.

## Flow

Referenced by developers, end-users, automated GitHub releases, and documentation links.

## Integration

Serves as the central user-facing and developer documentation repository.
